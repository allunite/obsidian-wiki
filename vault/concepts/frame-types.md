# Frame Types

AllUnite defines 13 frame type codes used in inventory management:

| # | Type | Code | Placement |
|---|------|------|-----------|
| 1 | Billboard | OTD | Outside |
| 2 | TV size (≤150") | MNT | Outside/Inside |
| 3 | On top of building | TPP | Outside |
| 4 | MUPI (ground structure) | MUP | Outside/Inside |
| 5 | Wall (indoor ad surface) | WAL | Inside |
| 6 | Clock (time/weather/info) | CLK | Outside |
| 7 | Wrap | WRP | Outside/Inside |
| 8 | Banner (outside, no foundation) | BAN | Outside |
| 9 | Tower or Pillar (2–4 sides) | TWR | Outside/Inside |
| 10 | Transport banner | TRN | Outside/Inside |
| 11 | News stands media / Kiosk | NSK | Outside |
| 12 | Bus Shelter | BSH | Outside |
| 13 | Others | OTH | Outside/Inside |
