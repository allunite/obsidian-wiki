# Source: Frame Parameters

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Inventory/Frame Parameters.md`

## Summary

Lists all configurable frame parameters: Frame ID (+ Alternative Frame ID), Period of Operation, Height and Width, Movement Type (Static/Dynamic Mechanical/Digital), Loop Duration, Insert Duration, Total Insertions, Contents, Lighting Type, Lighting Period, and Service Always Displayed. Height/Width are critical for Visibility Adjustment calculation.

See [frame.md](../concepts/frame.md).
