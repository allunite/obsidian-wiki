# Source: Removing Inventory

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Inventory/Removing inventory.md`

## Summary

**Desired functionality, not yet implemented.** When a frame is removed it should be set to `Demolished` status. Effect: impression aggregation stops for that frame (and for the facility if it was the last active frame) from the date of status change. Historical re-aggregation still works. Effects on mirroring and multi-source mirroring are TBD.
