# Source: Metrics Terminology

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Metrics Terminology.md`

## Summary

Canonical definitions for all platform metrics: Total Traffic, ROTS, VAC, Visibility Adjustment, Viewable Impressions, Viewed Impressions, Visit Frequency, Unique Traffic, Reach, Frequency, Footfall (Total Traffic Cluster), Dwell Time (Screen and Cluster), and related cluster metrics. Notes known issues (midnight UTC double-count, Footfall sensor dependency). References GitHub Traffic job and Rundeck endpoint for Total Traffic calculation.

See concept pages: [total-traffic.md](../concepts/total-traffic.md), [rots.md](../concepts/rots.md), [vac.md](../concepts/vac.md), [impression.md](../concepts/impression.md), [dwell-time.md](../concepts/dwell-time.md), [footfall.md](../concepts/footfall.md), [unique-traffic.md](../concepts/unique-traffic.md), [reach.md](../concepts/reach.md), [visibility-adjustment.md](../concepts/visibility-adjustment.md).
