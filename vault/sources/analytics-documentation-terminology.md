# Source: Analytics Documentation / Terminology

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Terminology.md`

## Summary

Seed terminology document defining the core vocabulary of AllUnite's analytics platform. Covers six primary concepts: Facility, Insertion, Loop, Loop Duration, and the Inventory Module. Each entry provides synonyms used by clients and media planners.

Key concepts defined:

- **Facility** — physical advertising screen or structure (panel, site, structure, unit). One facility may have multiple frames (visible ad sides).
- **Frame** — each visible ad side of a facility; the basic inventory unit.
- **Insertion** — one advertisement shown on a screen (also: spot, play, ad slot). Has an insert duration.
- **Loop** — full sequence of insertions before they repeat (also: ad rotation, playlist, ad cycle).
- **Loop Duration** — total seconds to complete one loop (also: cycle time, play loop time).
- **Inventory Module** — platform section for managing all advertising inventory; frame is the basic unit.

The document notes that Analytics supports flexible setups where slot/loop parameters are not fixed.
