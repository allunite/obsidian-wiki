# Source: Frame Statuses

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Inventory/Frame Statuses.md`

## Summary

Defines all frame lifecycle statuses: New, Changed (auto), Ready, Suspended, Demolished, Unverified, Approved by AU/3P/Exhibitor, Declined by AU/3P/Exhibitor. Only Ready and Approved statuses shown in campaign manager. Traffic page shows all statuses.

See [frame-status.md](../concepts/frame-status.md).
