# Source: Traffic Analytics Solution - Video

**Raw path:** `raw/docs.allunite.com/Incoming Projects/Traffic Analytics Solution - Video.md`

## Summary

Exploratory idea for video-based traffic analytics. Three options: (1) Offline CCTV processing (previous day batch) — lower compute, needs zone configuration; (2) Real-time CCTV stream processing — real-time data, higher compute, needs zone configuration; (3) Camera installed inside screen facing same direction as ad — inherently aligned viewability data. Each option requires marking the screen viewable zone in the video.
