# Source: Clockify Manual

**Raw path:** `raw/docs.allunite.com/Operations/Clockify manual.md`

## Summary

Time-tracking guidelines: ±5–10 minute accuracy acceptable; always indicate the project (no description/tags required); connect Google Calendar to Clockify for ease; log time a few times per day rather than end-of-day. Use the copy button to duplicate meeting entries. Normal workflow: set activities in calendar after each task; always indicate project for every entry.
