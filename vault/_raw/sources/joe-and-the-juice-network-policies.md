# Source: Network Policies

**Raw path:** `raw/docs.allunite.com/Joe&TheJuice/Network policies.md`

## Summary

Full network policy document. 4-VLAN design: (1) Management — AllUnite/IT access only, (2) Guest — customer WiFi, internet-only, (3) PCI — payment terminals, isolated, (4) Sensors/IoT — AllUnite WiFi sensors and other IoT. Firewall matrix: inter-VLAN traffic blocked by default; only explicitly allowed flows permitted. WiFi configurations per SSID. PCI compliance requirements: Card data environment isolation, quarterly scans. Maintenance schedule: firmware updates, log review. Support tiers: L1 (store staff) → L2 (AllUnite ops) → L3 (network admin).
