# Source: User Settings

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/user_settings.md`

## Summary

Reference table of per-company user/platform settings (feature flags). Notable settings include: `campaign.settings.dynamicSlotDuration`, `campaign.settings.ignoreLoopLimit`, `dashboard.hideForecast`, `dashboard.hideImpressions`, `dashboard.showLidarData`, `dashboard.showRealtimeVisitors`, `dashboard.useModelledDwellTime`, `monitoring.boxes` (offline box notifications), `providers.demographics` (default: areas), `providers.roadSegment` (default: openstreetmap).
