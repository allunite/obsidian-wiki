# Source: Linking Rules

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Inventory/Linking rules.md`

## Summary

Rules for linking sensor-less facilities to sensor-equipped facilities. Two contexts: outdoor linking (nearest same-category facility by direct distance) and cluster linking (nearest same-cluster same-category sensor; fallback to same cluster any category, then same city, then nearest city). Cross-cluster linking distributes evenly across sensors respecting location (entrance → entrance).

See [linking-rules.md](../concepts/linking-rules.md).
