# Source: Traffic+Demographics by Links/Zones

**Raw path:** `raw/docs.allunite.com/Data methodologies/3rd-party data/Traffic+demographics by links%2Fzones.md`

## Summary

Describes request/response format for 3rd-party traffic and demographics data by road links and zones. Request: JSON list of zones with `zone_id` and OpenStreetMap `road_links`. Response: (1) by road link — daily trips by transport mode (pedestrian, bicycle, public_transport, car); (2) by zone — `traffic_total`, `traffic_unique`, trips by mode and demographics. Requested for Mexico, Brazil, other countries.
