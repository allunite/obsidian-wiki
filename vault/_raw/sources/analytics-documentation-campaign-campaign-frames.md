# Source: Analytics Documentation / Campaign / Campaign Frames

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Campaign/Campaign Frames.md`

## Summary

Describes two methods for configuring frames in a campaign: filtering (campaign filters, frame attribute filters, tag filters, POI filters, manual map selection) and loading (packages, CSV/Excel). Rules: for new campaigns, all `Ready` or `Approved` frames are available; once frames are loaded, further filtering is limited to that set.

See [campaign.md](../concepts/campaign.md) for full context.
