# Source: DataBase Query

**Raw path:** `raw/docs.allunite.com/Operations/DataBase query.md`

## Summary

SQL reference snippets for PostgreSQL and ClickHouse. PostgreSQL: query `box_versions` by MAC address or facility_id to see sensor history. ClickHouse: query `allunite.raw_devices_seen_buffer` for raw sensor data by box MAC; query `facility_dict` to check if a facility has real data; find company number via `allunite.box_dict`.
