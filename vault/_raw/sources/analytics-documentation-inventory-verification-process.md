# Source: Verification Process

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Inventory/Verification process.md`

## Summary

Two levels of verification: **Standard** (GPS location, ID check, north angle, screen side placement) and **Extended** (adds segment review via Google Street View, cone corrections, photos). Verification does not change visibility cone segments — those can only be changed manually. Third-party tools like Ramboll only affect which segments fall inside the cone, not frame settings. Client verification procedure: select "Approved by AU" item, check coordinates/angle/side/cluster schema, approve or decline with comment.
