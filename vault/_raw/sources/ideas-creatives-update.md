# Source: Ideas / Creatives Update

**Raw path:** `raw/docs.allunite.com/Ideas/Creatives update.md`

## Summary

Idea: Improve creative (video/image) handling in the platform. Features: video frame extraction from the middle of the clip; image previews in list and detail views; store creative files on S3; hover previews in list view; CMS system integration; scheduling support. Candidate tools: kive.ai/tools/video-to-gif (GIF generation from video), turboscribe.ai (video transcription for descriptions).
