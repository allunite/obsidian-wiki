# Source: Roles

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Roles.md`

## Summary

Defines platform role identifiers and their access levels:

**Analytics roles:** trafficAnalytics, airportAnalytics, transitAnalytics, mallAnalytics, parkAnalytics  
**Campaign roles:** campaignAdmin (full access), campaignPlanner (create/modify/share, limited metrics), campaignPublisher (full access + Target Audience + extended filtering)  
**Other:** captiveStatistics, conversions, inventory (read-only), inventoryEditor, inventoryAuditor (can set Ready status)  
**Admin:** userManager, companies, localAdmin (impersonation within org), admins (full access)
