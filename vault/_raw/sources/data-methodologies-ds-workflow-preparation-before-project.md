# Source: Preparation Before Project

**Raw path:** `raw/docs.allunite.com/Data methodologies/DS Workflow/Preparation before project.md`

## Summary

DS project pre-flight checklist: verify access (git, analytics platform); identify PM as sole client contact; read ClickUp project transfer doc; check inventory/sensors/facility_dict; confirm deliverables; create project communication chat. Coordinations required with PM (client data, 3rd-party plans, demographics) and Ops (inventory completeness, timezone, categories, clusters, virtual facility linking).

See [ds-workflow.md](../methodologies/ds-workflow.md).
