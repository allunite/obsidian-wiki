# Source: Campaign Statuses

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Campaign/Campaign Statuses.md`

## Summary

Full state machine for campaign statuses with numeric codes (0–41). Includes Mermaid state diagram and folder groupings. Draft (0) → Proposal (20) → Proposal Changed (21) → Reserve (22) → Awaiting PI (23) → Request (24) → Ready (30) → Active (31, auto) → Delivered (32, auto) → Closed (40). Refused (41) reachable from most states.

See [campaign.md](../concepts/campaign.md).
