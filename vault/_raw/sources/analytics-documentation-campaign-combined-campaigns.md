# Source: Combined Campaigns

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Campaign/Combined Campaigns.md`

## Summary

Three ways to combine campaigns: Merge (independent new campaign from frame union), Combined (linked/live — updates when base campaigns' frame lists change), Grouped (metrics-only aggregated reporting dashboard, no campaign parameters). See [campaign.md](../concepts/campaign.md).
