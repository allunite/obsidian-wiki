**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Inventory/Cluster modules in Analytics.md`

## Summary

Maps cluster categories to analytics modules: Mall Analytics (Mall, Supermarket), Park Analytics (Park, Golf Club, Ski_Resort, Golf_Resort, Arena), Transit Analytics (Taxi Rank, Transport Hub, Rail, Metro, Ferry, Train, Gas_Station, Underground, Parking Hall), Airport Analytics (Airport). Category names are prefix-matched, case-sensitive.

See [cluster.md](../concepts/cluster.md).
