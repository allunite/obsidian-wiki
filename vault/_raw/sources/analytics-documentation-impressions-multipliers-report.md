# Source: Impressions Multipliers Report

**Raw path:** `raw/docs.allunite.com/Analytics Documentation/Impressions Multipliers Report.md`

## Summary

Also called the "Hourly Forecasted Report." Found in Traffic Dashboard > Traffic Filters > "Hourly Forecasted Report." Uses last 13 full weeks (or less if shorter data exists) of Viewed Impressions data, calculates hourly averages per weekday, divides by slots per hour. Output: matrix of weekday × hour.
