**Raw path:** `raw/docs.allunite.com/Operations/Facility WiKi/Installation docs - Draft.md`

## Summary

WiFi sensor installation material guide using a traffic-light zone classification: Red zone (concrete, metal, thick masonry — strong signal blocking, avoid direct placement), Yellow zone (mixed/lightweight materials — moderate attenuation), Green zone (glass, drywall, wood — minimal attenuation). Used for site surveys before deploying sensor hardware.
