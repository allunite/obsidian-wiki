# Source: WiFi Methodology

**Raw path:** `raw/docs.allunite.com/Data methodologies/WiFi methodology.md`

## Summary

Comprehensive WiFi sensor methodology: MAC address types (UAA, LAA, trusted), filtration rules (signal level < -74dBm excluded; permanent devices ≥5 consecutive hours excluded), session counting (15-minute gap rule), signal frequency (1-300 seconds depending on device state). Correlation between LAA "randomized" MACs and total devices/dwell time used for people-count estimation. Current accuracy: 94% ± 5%.

See [wifi-methodology.md](../methodologies/wifi-methodology.md).
